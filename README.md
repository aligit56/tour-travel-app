# Tour Website (React)

A responsive Tour & Travel website built with React, Vite, and Tailwind CSS.

## Features

- Responsive travel homepage with animated hero video and parallax motion
- Reusable data-driven navigation, service, tour, booking, footer, and topic components
- Full journeys catalog with destinations and PKR pricing
- Booking form with guest controls and confirmation state
- Working Journal, company, support, contact, and social media links

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run build
npm run lint
```
